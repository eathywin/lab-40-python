# Підпис MAVLink 2

Для захисту команд обрано MAVLink 2 signing. Після налаштування ключа QGroundControl показав **Signing OK** та один signing stream. Стан збережено на скриншоті `Pasted image (2).png`.

Підпис додає перевірку походження та цілісності повідомлення. Часова мітка й стан приймача використовуються для контролю повторів. Вміст MAVLink залишається доступним для аналізу у Wireshark: signing забезпечує автентичність, тоді як шифрування відповідає за приховування даних.

## Налаштування та перевірка

1. Запустити локальний PX4 SITL і QGroundControl.
2. У QGC відкрити **Application Settings → Telemetry → Signing Key**, налаштувати ключ на довіреному локальному з'єднанні.
3. Перевірити **Signing OK** у Link Status.
4. Передати свіжу підписану команду й перевірити COMMAND_ACK та стан симулятора.
5. Порівняти її з непідписаною командою та повтором раніше прийнятого підписаного повідомлення. Для кожного випадку зберігати відповідь, телеметрію та доступні повідомлення приймача.

Для повтору початкових байтів використовується [capture-and-replay.py](../insecure/capture-and-replay.py). Перевірка виконується в одній сесії симулятора. Налаштування signing звіряються з документацією встановленої версії PX4.

## Спостереження

| Матеріал | Що зафіксовано |
|---|---|
| `Pasted image (2).png` | QGroundControl: Signing OK, активний signing stream |
| `Pasted image (3).png` | Після запуску тестового клієнта дві відповіді COMMAND_ACK не надійшли в межах тайм-ауту; програма вивела None |

У звіті ці спостереження розглядаються разом із принципом перевірки підпису та свіжості повідомлень. Для порівняння проходження команд використовуються відповідь приймача й стан SITL.

Ключ signing і запис його початкового передавання зберігаються локально. [Документація PX4](https://docs.px4.io/main/en/mavlink/message_signing), [MAVLink signing](https://mavlink.io/en/guide/message_signing.html).
