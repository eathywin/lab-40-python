# Лабораторне середовище

Роботу виконано на власному стенді: Kali Linux, власна точка доступу й тестовий клієнт, локальні Python-процеси та PX4 SITL.

Для демонстрації TCP/TLS використано навчальний маркер і вигадані облікові дані. Команди MAVLink адресовано локальному симулятору. Wi-Fi-досліди стосуються власної лабораторної мережі; під час повторення стенд відокремлюється від робочої мережі.

Приватні ключі, справжні паролі й матеріали передавання ключа signing залишаються локальними. Для показу результатів використовуються записи трафіку та скриншоти без переписування секретів у текст звіту.
