# Власна точка доступу

Стенд: TP-Link TL-WR850N v2 і власний тестовий клієнт; USB-адаптер Mercusys 2c4e:0102. Канал AP змінювався між сеансами, тому його не слід вважати постійно рівним 2 або 4.

Для нового досліду AP має бути від'єднана від WAN/виробничої мережі. Налаштування й радіооперації виконуються вручну; Makefile їх не запускає.

## Захоплення

Спочатку перевірити інтерфейс:

```bash
iw dev
sudo airmon-ng check
```

NetworkManager/wpa_supplicant або інший запущений сканер можуть переналаштовувати той самий адаптер. На окремому лабораторному адаптері потрібно усунути цю конкуренцію. Зупинення мережевих служб відключає звичайний Wi-Fi; Ethernet може використовуватися для доступу до роутера.

```bash
sudo airmon-ng start wlan0
sudo airodump-ng wlan0
```

Номер угорі - поточний канал сканера; `CH` у рядку потрібної BSSID - канал AP. Зупинити сканування, ввести актуальний канал і BSSID власного AP:

```bash
sudo airodump-ng --channel КАНАЛ --bssid BSSID_ВЛАСНОГО_AP --write wifi_lab/captures/new-session wlan0
```

Після початку захоплення перепід'єднати власний клієнт через його меню Wi-Fi. Для цього не обов'язково надсилати кадри деавтентифікації. Перевірити EAPOL у Wireshark, зберегти PCAP і дату сеансу.



## Повернення до звичайного Wi-Fi

Після завершення зупинити захоплення через Ctrl+C. Для наявного інтерфейсу wlan0:

```bash
sudo ip link set wlan0 down
sudo iw dev wlan0 set type managed
sudo ip link set wlan0 up
sudo systemctl restart NetworkManager wpa_supplicant
```

Якщо airmon-ng створив wlan0mon, спочатку зупинити саме цей monitor-інтерфейс через `sudo airmon-ng stop wlan0mon`. Назву перевірити в `iw dev`.

## Що перевірено

`captures/handshake.pcap` містить чотири EAPOL Key повідомлення 1-4. Мінімальний файл не має beacon із SSID, тому для повторної словникової перевірки знадобиться точний SSID навчальної мережі. Пароль не зберігається в README. Для локальної перевірки власного запису й власного навчального словника:

```bash
aircrack-ng -b BSSID_ВЛАСНОГО_AP -e 'НАВЧАЛЬНИЙ_SSID' -w /шлях/до/власного-словника.txt wifi_lab/captures/handshake.pcap
```

Результат контрольної словникової перевірки показано на скриншоті KEY FOUND. Під час повторення зберігаються PCAP, SSID і журнал перевірки; сам пароль у звіт не переноситься.
